Vapor Control Plane · 设计原型

后台界面原型 · Steam 风格默认主题

原型先行 · 本阶段不改线上页面（src/Vapor.ControlPlane/wwwroot 保持原样）· 数据均为示例。

4 套主题可切换（右上角）
默认主题为 Steam 风格（深蓝灰底 #1b2838 / #171a21、卡片式布局、克制蓝高亮 #66c0f4、正文浅灰 #c7d5e0）。主题层由 theme.css 的 --t-* 语义令牌驱动，切换主题只覆盖令牌、不改结构；后续加主题无需改动页面。

三个后台页面原型

覆盖线上 admin / dashboard / gamedata 三页的真实布局：Hero、状态卡、面板、表单、表格、列表、筛选条与分页。

admin.html

Vapor Admin Console · 管理视图

  • Hero + 实时流状态 + API Key 框 + 页间导航
  • 5 张状态卡（Jobs / Running / Finished / Agents / Sessions）
  • 16 个面板：创建任务、任务列表、作业详情、Agent 概览、活动会话、认证挑战、账户管理、交易与确认、仓库归集、市场与认领、爬虫计划管理、配置管理、插件管理、脚本仓库、脚本编排、事件日志

dashboard.html

Vapor Dashboard · 只读总览

  • Hero 侧栏 + 实时流状态 + 页间导航

主题体系

Steam 为默认；其它主题作为可切换项，全部走同一套 --t-* 语义令牌。
steam · 默认
midnight · 午夜
daylight · 日间
ember · 暮橙
语义令牌steam（默认）midnightdaylightember用途
--t-bg#171a21#0e1114#eef1f4#1c1512页面底色
--t-card#1b2838#151a20#ffffff#261c17面板 / 卡片
--t-brand#66c0f4#4f9edb#1666a8#e8863c高亮 / 主按钮 / 链接
--t-fg#c7d5e0#d6dde4#1b2838#e8d9cd正文浅灰（steam）
--t-border#2a475e#262d36#d4dbe2#4a2f24分隔 / 描边

结构令牌（间距 / 圆角 / 字号 / 动效）与主题无关，见 theme.css 顶部 :root。
