# Doc–code consistency audit

- **Audit scope**: `README.md`, `docs/**` (23 files), and the public GitHub front door (About description / topics).
- **Baseline**: repository source (`src/`, `tests/`, `docker-compose.yml`, CI workflows).
- **Audit date**: 2026-10-13.
- **Method**: every technical claim traced back to source at `file:line`; for negative claims, first confirm the search path exists, then judge "docs ahead of code".
