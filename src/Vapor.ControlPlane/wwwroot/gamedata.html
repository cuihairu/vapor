Vapor · game data

游戏数据字典与采集记录

Vapor 的数据抓取底座覆盖 Steam 公开商店端点（应用详情、搜索、价格、市场挂单）， 匿名可达、不涉及任何账号凭证；多账号分片采集（crawl）把应用列表轮转分配给已入库账号， 仅用于分摊频控与审计归属。本页只读：字段字典说明每个模型的语义、来源与缓存层级， 下方展示采集计划、轮次与逐应用结果。

→ 实时面板（dashboard.html） → 管理视图（admin.html）
无凭证约束：商店端点匿名可达，采集不接触任何 secret；但分片任务经由常规作业队列派发， payload 无凭证时 agent 一律回放该账号的已入库会话—— 因此采集池内的账号必须先在某个 agent 完成登录入库，否则该账号的分片会失败（不影响其他分片）。
